# Linux Distributions 🐧

A **Linux distribution (distro)** is a complete operating system built around the Linux kernel.

The Linux kernel is the core of the system, while a distribution combines the kernel with system tools, libraries, package management, applications, and configuration.

---

## What is a Linux Distribution?

The **Linux kernel alone is not a complete operating system** for everyday use.

A Linux distribution combines the Linux kernel with the additional software required to create a usable operating system.
