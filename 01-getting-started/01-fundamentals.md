# Linux Fundamentals 🐧

## What is Linux?

Linux is an **open-source operating system kernel** that manages computer hardware and system resources.

In everyday usage, the word **Linux** is commonly used to refer to operating systems built around the Linux kernel.

Examples include:

- Ubuntu
- Debian
- Fedora
- Arch Linux
- Linux Mint

---

## What is an Operating System?

An **Operating System (OS)** is software that manages a computer and provides a platform for applications to run.

Examples of operating systems include:

- Linux
- Windows
- macOS
- Android

The operating system manages resources such as:

- CPU
- Memory
- Storage
- Hardware devices
- Running programs

---
